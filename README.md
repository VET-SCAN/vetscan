# VET-SCAN

Sitio web estático de VET-SCAN, listo para publicar con GitHub Pages.

## Publicación
1. Sube todos los archivos de esta carpeta a la raíz del repositorio.
2. En GitHub: Settings → Pages → Deploy from a branch → rama `main` → carpeta `/ (root)`.
3. Guarda y espera a que GitHub Pages publique el sitio.

## Dominio personalizado
Configura el dominio desde Settings → Pages → Custom domain y luego ajusta los DNS en Hostinger según la documentación de GitHub Pages.
